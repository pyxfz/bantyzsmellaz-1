vulnerabilities facing AI systems (OWASP LLM Top 10, 2026 revision) with real-world incidents
and mitigations. **Part II** evaluates the offensive, guardrail-removed, and specialist cyber
models a red-team practice can legally field — capabilities, pricing, benchmarks, workflow
integration, and the cheap-model techniques that close the gap to frontier labs.

## 2. Works like an app

This manual is an installable PWA: add it to your home screen and previously visited sections keep
working offline — including syntax-highlighted code blocks and wide comparison tables, which scroll
sideways instead of breaking the layout on phones.

<Aside type="caution" title="Authorized security testing only">
  Part II documents offensive-capable AI tooling for professional red-team, blue-team and defensive
  research under explicit written authorization. It is not advice to attack systems you do not own or
  have permission to test. Every vendor covered here requires authorization first — capability never
  supplies permission.
</Aside>
